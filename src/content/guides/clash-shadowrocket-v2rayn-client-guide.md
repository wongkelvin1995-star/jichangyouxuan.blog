客户端和机场经常被混为一谈。其实两者分工很清楚：**机场提供订阅（节点与规则的集合），客户端负责导入订阅并建立连接。** 选购时，你需要确认的是：服务商的订阅格式，能不能被你手上的设备和客户端顺利导入。

## 先看设备，再选客户端

下面按平台列出常见选择。客户端的维护状态与上架情况会变化，请以各项目主页和应用商店当前信息为准，本文不做下载渠道的推荐。

| 平台 | 常见客户端 | 备注 |
| --- | --- | --- |
| Windows | Clash 系客户端（如 Clash Verge Rev）、v2rayN、sing-box | Clash 系客户端目前多基于 Mihomo 内核 |
| macOS | Clash 系客户端、sing-box、小火箭（Apple 芯片机型） | 以实际可用版本为准 |
| Android | v2rayNG、Clash 系客户端、sing-box、Hiddify | 注意安装包来源 |
| iOS | 小火箭（Shadowrocket）、sing-box 等 | 通常需要在 App Store 获取，付费与地区限制以商店为准 |

没有哪一个客户端「最好」，只有「最适合你的设备和习惯」。如果你同时有 Windows 电脑和 iPhone，就要确认服务商的订阅在这两类客户端上都能用。

## 客户端与机场订阅的区别

安装客户端不等于拥有了服务。你还需要从机场获取**订阅链接**，再把它导入客户端。订阅链接相当于你的账户凭证：谁拿到它，谁就能使用你的流量。

## 机场订阅的常见格式

- **Clash 配置格式：** 通常是 YAML，包含节点与规则，Clash 系客户端可以直接导入；
- **通用订阅格式：** 一组节点链接，经过编码，适用于 v2rayN、v2rayNG、小火箭等；
- **sing-box 配置格式：** JSON 配置，供 sing-box 与相关客户端使用。

购买前请确认服务商是否提供与你的客户端匹配的格式。如果需要使用格式转换，请优先使用服务商自己提供的转换方式，因为把订阅链接填进陌生的在线转换站，等于把凭证交给了第三方。

## Clash 教程：导入机场订阅的基本步骤

以 Windows / macOS 上常见的 Clash Verge Rev 为例（其他 Clash 系客户端的菜单名称可能略有不同）：

> 灵动云用户先看这里：灵动云目前以官方专用客户端为主，通用订阅需要通过客服获取，具体以[灵动云详细页](/airports/lingdongyun/)和客服说明为准。

1. 在机场后台复制 Clash 订阅链接（常见入口叫「一键订阅」或「复制订阅地址」），不要发给别人；
2. 打开客户端的「订阅」页，粘贴链接并点击「导入」；导入后列表里会出现这个订阅，点选它，让它处于启用状态；
3. 到「代理」页查看节点并选择一个，模式先用「规则」，只有确实需要时才切换到「全局」；
4. 在设置里开启「系统代理」，需要代理的网页和应用就会通过所选节点连接；不读取系统代理的软件，可以改用「虚拟网卡模式」（TUN）；
5. 连不上时先更新订阅、换一个节点，再按下文的排查顺序检查。

**小火箭（Shadowrocket，iOS）：** 点右上角「＋」，类型选「Subscribe」（订阅），粘贴订阅链接后保存；回到首页选中一个节点，打开顶部的连接开关。第一次连接时 iOS 会提示添加 VPN 配置，按提示允许即可。

**v2rayN（Windows）：** 在「订阅分组」里打开「订阅分组设置」，添加订阅并粘贴链接，保存后执行「更新订阅」；节点出现后选中一个，再把底部的系统代理设为「自动配置系统代理」。

不同版本的菜单名称可能略有差异，以软件界面为准。客户端请只从项目官方页面或正规应用商店安装。

## 多设备使用要注意什么

1. **设备数量限制：** 套餐往往限制同时在线的设备数，手机、电脑、平板、电视盒子加起来要不要超限，下单前确认；
2. **订阅更新：** 节点调整后需要更新订阅，部分客户端支持自动更新，请了解其更新频率；
3. **订阅链接保密：** 不要把链接发到公开群或截图分享；
4. **流量共享：** 多台设备共用同一套餐流量，用量会叠加，可用[流量估算器](/budget-guide/#traffic-estimator)重新估算。

## 基础安全检查

- 只从项目官方页面或正规应用商店下载客户端，避开来源不明的「修改版」；
- 安装前核对来源，不要因为方便而随意关闭系统的安全提示；
- 不把订阅链接粘贴给陌生人，也不上传到陌生网站；
- 怀疑订阅泄露时，立即向服务商申请重置；
- 用独立邮箱注册，避免重复使用重要密码。

## Clash 无法连接、订阅导入失败怎么排查

第一次导入订阅，最常见的问题其实不复杂。可以按下面的顺序检查：

1. 链接是否完整复制，有没有多出空格或少了字符；
2. 订阅格式与客户端是否匹配，比如把通用订阅填进了只接受配置文件的客户端；
3. 设备的系统时间和网络是否正常，时间偏差有时会导致连接失败；
4. 是否超出了套餐的同时在线设备数，或者套餐已过期、流量已用完；
5. 客户端是不是已经长期不更新，换一个仍在维护的版本再试。

如果以上都没问题，再向服务商的客服反馈，并附上客户端名称、版本和报错信息。这样的反馈更容易被快速解决，也能帮你判断这家服务的支持是否靠谱。

## 一个简单的选择流程

1. 列出你要使用的设备和系统；
2. 为每台设备挑一个常见客户端，并确认它的当前维护情况；
3. 向服务商确认订阅格式与客户端兼容性、设备数限制；
4. 购买月付，在每台设备上都导入一次订阅，确认可以正常使用；
5. 满意后再考虑更长的付款周期。
